The file embedding/potion-base-8m.bin is a converted copy (8-bit vectors and the word-piece
vocabulary) of the static embedding model "potion-base-8M" by The Minish Lab (Stephan Tulkens
and Thomas van Dongen):

  https://huggingface.co/minishlab/potion-base-8M
  revision bf8b056651a2c21b8d2565580b8569da283cab23

The model card gives its licence as MIT. The model repository carries no licence file of its
own; the text below is the MIT licence as published with the authors' Model2Vec project
(https://github.com/MinishLab/model2vec), with which the model was made.

potion-base-8M is distilled from BAAI/bge-base-en-v1.5 (https://huggingface.co/BAAI/bge-base-en-v1.5),
also MIT-licensed, Copyright (c) 2022 staoxiao, and uses the vocabulary of BERT base uncased.
